# Changelog

## Подготовка к публичному запуску

- Вход в публичной сборке только через MAX; demo-аккаунты, mock API и `/auth/mock` исключены из bundle.
- Добавлены экран открытия через MAX и повтор авторизации с актуальным `initData` после ошибки связи.
- Demo-сборка включается явно; Docker по умолчанию собирает production.
- Добавлен frontend CI с lint, unit-тестами, типизацией, проверкой bundle и E2E против реального backend.
- В аудите показываются переходы статусов, понятные счётчики импорта и известные имена авторов.
- Расширены E2E: повторный/ошибочный импорт, правки закрытой сессии, CSV, восстановление истории, сетевой повтор, дубликаты, чужая группа и истёкший QR.

## P1 — управление группой и аудит

### Добавлено

- Импорт состава группы из CSV через настоящий backend, с результатом импортированных и уже добавленных студентов.
- Одиночное добавление студента переведено на тот же CSV endpoint.
- Карточка статистики группы и журналы аудита группы и занятия.
- Mock API для импорта, статистики и аудита; тесты идемпотентности и атомарной ошибки импорта.
- Браузерный сценарий импорта, статистики и аудита против реального backend.

## Следующий P0-релиз

### Добавлено

- Автоматическая отметка студента сразу после входа по QR-ссылке.
- Управление составом группы и mock-контракт добавления по MAX ID.
- Восстановление активного занятия после повторного открытия.
- История занятий, просмотр сохранённых списков и скачивание CSV.
- Ручное добавление, удаление и изменение статуса отметки с обязательной причиной.
- Статусы «вовремя»/«опоздал» и источник ручной отметки.
- Браузерный Playwright-тест frontend ↔ настоящий backend.
- Новое название продукта «QR-отметка».

## frontend-v0.1.0 — 2026-09-28

Первый P0-релиз frontend проекта.

### Добавлено

- React 19, TypeScript, Vite, MAX UI и MAX Bridge.
- TanStack Query для серверного состояния и polling.
- Авторизация через MAX и dev-only mock-вход с четырьмя синтетическими пользователями.
- Преподавательский путь: выбор группы, запуск занятия, ротация QR, live-список и итоги.
- Студенческий путь: `start_param`, подтверждение, успех и отдельные бизнес-ошибки.
- Адаптивный интерфейс для MAX Mobile и Web.
- ESLint, Prettier, Vitest и контрактные тесты mock API.
- Документация запуска и согласованный frontend/backend контракт.
