# Frontend

Владелец: Никита. Рома помогает с UX и текстами интерфейса.

Планируемый стек: React, TypeScript, Vite, MAX UI и MAX Bridge. Клиентский код размещается в `src/`. Подробную структуру экранов и компонентов Никита определяет после проверки интеграции с MAX.

Здесь появятся инструкции запуска и сборки. Данные `initData` отправляются на backend для проверки; доверять `initDataUnsafe` как подтверждению личности нельзя.
