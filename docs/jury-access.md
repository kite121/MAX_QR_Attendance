# Проверка проекта жюри

Для проверки нужны два аккаунта MAX: один для преподавателя и один для студента. Отдельные логины и пароли проекта не требуются. Код доступа к тестовой группе указан на первом слайде PDF-презентации.

## Вход и выбор ролей

1. Откройте [бота «QR-отметка» в MAX](https://max.ru/t349_hakaton_max_bot) и запустите Mini App. Прямое открытие сайта в обычном браузере не передаёт приложению данные входа MAX.
2. На экране приложения нажмите **«Для жюри»**, введите код с первого слайда презентации и выберите **«Стать преподавателем»**.
3. Под другим аккаунтом MAX повторите вход и выберите **«Присоединиться как студент»**. Оба аккаунта получат доступ к синтетической группе **«Проверка жюри»**.

Роль сохраняется после повторного входа. При необходимости её можно изменить на странице **«Для жюри»** тем же кодом.

## Основной сценарий

| Действие | Ожидаемый результат |
| --- | --- |
| Преподаватель открывает группу «Проверка жюри» и создаёт занятие | Появляются активная сессия и обновляемый QR-код |
| Студент сканирует QR и открывает ссылку в MAX | Отметка создаётся автоматически, без кнопки подтверждения; студент видит результат |
| Преподаватель смотрит список занятия | Студент появляется в списке один раз |
| Студент повторно открывает тот же QR | Вторая отметка не создаётся |
| Преподаватель закрывает занятие, открывает историю и скачивает CSV | Сессия сохраняется в истории; CSV содержит данные посещаемости |
| Преподаватель вручную корректирует запись | Изменение видно в списке и журнале действий |

QR-код действует недолго. Если ссылка успела устареть, студент сканирует текущий код с экрана преподавателя. Для сквозной проверки преподавателю и студенту нужны разные аккаунты MAX.

- [Mini App](https://app.qr-otmetka.ru) и [OpenAPI 3.1](https://app.qr-otmetka.ru/api/v1/openapi.json).
- [Исходный код](https://github.com/kite121/MAX_QR_Attendance). Зафиксированный commit hash указан на первом слайде PDF.
- [Сценарий API-проверки](DATA-API.yaml) и [основной пользовательский сценарий](user-scenario.md).

Код из PDF даёт доступ только к выбору роли в тестовом сценарии. Он не является токеном бота, паролем сервера или доступом к данным реальных учебных групп.
